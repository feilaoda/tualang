# 数组（`T[]` / `T[N]`）规范

Status: Frozen

本文件定义 CAI 的数组类型、字面量、索引、边界检查与迭代。

---

## 1. 类型
- `T[]`：动态数组（拥有型容器，默认 move-only）。
- `T[N]`：定长数组（值类型，内联存储；是否为 copy 由元素类型决定）。

可空性：
- 数组值不可为 `null`（见 `cai/docs/spec/null.md`）。

---

## 2. 字面量
数组字面量使用方括号：
- `[expr1, expr2, ...]`
- `[]` 表示空数组字面量（必须在可推断上下文中使用，否则编译错误）。

元素求值顺序：从左到右（见 `cai/docs/spec/expressions.md`）。

---

## 3. 索引与边界
- `a[i]`：
  - `i` 必须是整数类型；
  - 默认进行边界检查；越界为运行时错误。

性能模式（可选）：
- 编译器可提供 `--unchecked-index` 等全局开关跳过边界检查，但必须显式开启。

---

## 4. 赋值与所有权
元素访问（表达式位置）冻结为：
- 若 `T` 为 copy type，则 `a[i]` 的结果类型为 `T`（按值复制）。
- 若 `T` 为 move-only，则 `a[i]` 的结果类型为 `Ref<T>`（共享只读借用），禁止按值读取。

元素写入冻结为：
- `a[i] = v` 需要 `a` 是可写的数组值（非 `const`），并会把 `v` move/复制进槽位（按 `T` 的 copy/move 规则）。

---

## 5. 迭代
`for v in a { ... }` 的语义冻结为：
- 若 `T` 为 copy type：`v: T`（复制）
- 若 `T` 为 move-only：`v: Ref<T>`（共享只读借用）

`for v, i in a { ... }` 的语义冻结为：
- `v` 同上（copy 或 `Ref<T>`）
- `i: usize`（索引）

---

## 6. 常用 API（标准库约定）
数组方法建议放在标准库，但其语义需要冻结（至少签名与错误行为）：
- `len() -> usize`
- `push(v: T)`
- `pop() -> Option<T>`
