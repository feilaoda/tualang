# 诊断与错误输出规范

Status: Frozen

本文件定义 CAI 的诊断输出格式与最低质量要求，便于测试与工具链集成。

---

## 1. 输出格式
- 编译期错误：
  - `path:line:col: error: <message>`
- 编译期警告（若实现）：
  - `path:line:col: warning: <message>`

行列从 1 开始计数。

---

## 2. 最低要求
- 语法错误必须定位到 token（或最近可定位位置）。
- 类型错误必须指出期望类型与实际类型（至少字符串化）。
- 导入错误必须显示尝试过的搜索路径（便于定位配置问题）。
