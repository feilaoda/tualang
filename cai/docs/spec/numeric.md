# 数值类型与运算规范

Status: Frozen

本文件定义 CAI 的整数/浮点类型、字面量定型、溢出、算术与位运算语义。

---

## 1. 数值类型集合

### 1.1 有符号整数
- `i8` `i16` `int`(i32) `long`(i64) `isize`(指针宽度)

### 1.2 无符号整数
- `u8` `u16` `u32` `u64` `usize`(指针宽度) `byte`(u8)

### 1.3 浮点
- `f16` `f32`(别名 `float`) `f64`(别名 `double`) `bf16`
- `f8`/`bf8`：定义为“存储类型”，不参与标量算术（仅允许与 `u8/byte` 互转，用于量化/字节级处理）。

---

## 2. 字面量定型

### 2.1 整数字面量
- `123` 默认类型为 `int`，但在有目标类型上下文时可定型为目标整数类型（若不溢出）。
- `123L` 默认类型为 `long`，同理可在上下文中定型为目标整数类型。

溢出：
- 若字面量无法表示为目标类型，编译错误。

### 2.2 浮点字面量
- `1.0` 默认类型为 `double`，但在上下文中可定型为 `float/f16/bf16/double`。

---

## 3. 算术运算

### 3.1 `+ - * / % **`
规则：
- 运算两侧必须为数值类型。
- 整数与浮点混用需显式 cast（避免隐式精度损失）。

### 3.2 整数除法
除法语义冻结为：
- `a / b` 对整数执行“截断向零”的商（与 C 类似）。

除零：
- 除零为运行时错误（必须给出定位）。

溢出：
- CAI 的整数算术溢出语义为 **wrap**（按位宽截断，二进制补码取模）：
  - 对无符号与有符号整数均定义为 modulo `2^bits` 的结果（避免 C/LLVM 未定义行为）。

---

## 4. 位运算与移位

### 4.1 位运算
- 一元：`~x`
- 二元：`a & b`、`a | b`、`a ^ b`

约束：
- 仅允许整数类型。
- 有符号/无符号混用需显式 cast。

### 4.2 移位
- `a << n`、`a >> n`

移位语义冻结为（避免 C/LLVM UB）：
- `n` 会按位宽掩码：`n = n & (bits-1)`。
- `>>`：
  - 无符号为逻辑右移；
  - 有符号为算术右移（符号扩展）。

---

## 5. 自增/自减
- `++x`/`--x`/`x++`/`x--` 仅允许作用于“可写的整型 lvalue”（变量或可写字段/元素）。
- 对 `const` 绑定为编译错误。

---

## 6. cast（数值转换）
允许的数值 cast 形态（语法见 `cai/parser.g4`）：
- Java 风格：`(T)expr`（仅对内建数值目标类型定义）
- 后缀：`expr as T`（仅对内建数值目标类型定义）

约束：
- 数值 cast 为按位宽截断/扩展与 IEEE 浮点转换的确定性语义；
- 禁止把数值 cast 用于指针/引用/结构类型。
